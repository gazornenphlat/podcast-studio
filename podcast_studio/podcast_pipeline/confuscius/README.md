# Confuscius

`python confuscius/confuscius.py --script script.txt [--tiktok]`

Same look as COCku (dim + centered scrolling script, crossfades) but a fully
separate process: its own assets, config, prefix `CONFUSCIUS`, counter and
output. No alt-ending.

Output (`confuscius/output/`): `CONFUSCIUS-001_Title.mp4`, `.mp3`, `_intro.*`,
`_middle.mp4`, `_image_prompt.txt`, optional `_tiktok.mp4`.
Look and feel: `video.cocku` block in `confuscius/config.json`.
